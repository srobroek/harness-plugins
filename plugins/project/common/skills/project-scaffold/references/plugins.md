The plugin sources and public catalog are in https://github.com/srobroek/harness-plugins.
Pick per project; do not re-add what the host already has globally.

## 1. See what is installed

- Global: `plugins` in `~/.config/opencode/opencode.json`; `opencode plugin list` shows
  installed plugins. The generated table in section 3 lists the plugins meant to be global;
  trust the file, not the table.
- Project: `plugins` in the project's `opencode.jsonc`, if it exists.

## 2. List every available plugin

Use either of these; each helps match plugin descriptions to the project:

1. `find_tools_scan` with a few capability words (for example `rust lint`, `issue tracking`)
   and `sources: ["local", "catalog"]`. `local` is what is installed; `catalog` is the
   current repository's `.claude-plugin/marketplace.json`. Read-only; it never installs.
2. Browse this repository's `plugins/<name>/package.json` files for descriptions and the
   `plugins/<name>/` directories for plugin sources. The root `README.md` lists the plugins.

`lib` is not a plugin. Other registries (npm, MCP registry, awesome-opencode) are
`find-tools`' job when this repository has no fit.


## 3. Global and per-project plugins

The project gets Beads only when it already has a `.beads/` store or the user chooses it.
Otherwise retain the existing tracker or ask which tracker they want.

## 4. Install into the project

From this repository, install a project plugin from its `opencode/` subdirectory, for example:

```sh
opencode plugin add 'github:srobroek/harness-plugins#main::path:plugins/beads/opencode'
```

For GitLab, choose the equivalent repository source for the configured forge host. For GitHub,
replace `#main` with a tag to pin a release; pins stop automatic updates. Check `opencode plugin
add --help`: if it writes global configuration, add the package spec to the project's `plugins` array instead:

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    "github:srobroek/harness-plugins#main::path:plugins/beads/opencode",
    "github:srobroek/harness-plugins#main::path:plugins/speckit/opencode"
  ]
}
```

Plugin options use the object form (`{ "package": "...", "options": {} }`). Then
`opencode plugin list` to confirm they load, and mention that a restart may be needed.

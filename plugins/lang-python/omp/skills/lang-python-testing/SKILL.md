# Python Testing

Use pytest and exercise public behavior. Parametrize input classes; use property-based testing
for parsers and invariants. Prefer real dependencies in integration tests and isolate external
services at boundaries. Keep fixtures small and explicit. Run tests from the project environment
and treat an empty test collection as no verification.

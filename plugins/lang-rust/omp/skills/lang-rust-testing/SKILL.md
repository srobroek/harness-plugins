# Rust Testing

Use `cargo-nextest` for unit and integration tests and run `cargo test --doc` for doctests. Add
property-based tests for invariants and parsers; use snapshots for stable, reviewable output.
Exercise concurrency and persistence with real dependencies where practical. Keep tests isolated
from shared files, ports, and databases.

# TypeScript Types

Keep `strict` enabled. Model valid states with discriminated unions and narrow unknown values at
boundaries. Use generics when they express a reusable relationship. Validate untrusted input with
Zod when runtime validation is required; infer static types from schemas where that reduces
separate definitions.

# TypeScript Profiling

Measure before optimizing. Use the runtime's CPU and heap profilers on representative workloads.
Separate startup, CPU, allocation, and I/O costs. Compare using the same runtime version, inputs,
and environment. Keep profiling tools out of runtime dependencies.

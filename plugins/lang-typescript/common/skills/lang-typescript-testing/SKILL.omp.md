# TypeScript Testing

Use the project's test runner and lockfile. Cover public behavior with focused unit and integration
tests. Use property-based tests for input invariants and mutation testing to assess test quality.
For workspaces, run the affected package first and the full workspace when shared code changes.
Treat empty test discovery as no verification.

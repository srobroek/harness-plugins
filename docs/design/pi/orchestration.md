# Orchestration and subagents

**Recommendation: adopt `pi-subagents` as the one subagent runtime; choose no goal/autonomy package for now.** Keep the OMP workflow policies and domain tooling as instructions, agents, formulas, and Pi extensions where they enforce behavior. The exact npm package is **`pi-subagents`**, not `pi-subagents-plugin`. The other subagent candidate, `@tintinweb/pi-subagents`, is a separate competing runtime.

The maturity figures below use npm’s latest published package metadata and weekly downloads for **2026-11-16-22**. GitHub star, commit, and open-issue counts are repository-level signals; for the `@narumitw/pi-goal` row, issue activity is for its monorepo, not that package alone.
